# MindCanvas 心幕 — 官网

全场景数字化心理健康生态系统的企业官网。

## 品牌定位

- **品牌名**：MindCanvas (心幕)
- **Slogan**：用 AI 编织心智的画布，守护每一颗心灵的晴空
- **核心理念**：科学（工程医学）与艺术（人文关怀）的融合

## 视觉规范

- **主色**：科技深蓝 `#0f2847`、`#1e3a5f`
- **辅色**：艺术暖橙 `#f97316`、治愈湖绿 `#0d9488`
- **风格**：流体渐变、画布纹理

## 本地预览

```bash
# 使用任意本地服务器，例如：
npx serve .
# 或
python3 -m http.server 8000
```

在浏览器中打开 http://localhost:3000 或 http://localhost:8000 预览。

## 页面结构

1. **Hero** — 英雄区：品牌主张与 CTA
2. **Legacy** — 十年积淀：1010 万+ 学生、500 万+ 验证、100% 数字化
3. **Solutions** — 产品矩阵：APP、Portal、Bot、Edu
4. **Technology** — 技术引擎：多模态学习、医学严肃性、动态量表
5. **About** — 关于心幕：团队、使命、愿景
6. **Contact** — 联系 CTA

## 技术栈

- 纯 HTML / CSS / JavaScript
- 无构建工具，可直接部署至任何静态托管
